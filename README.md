# Новогодняя деревня

Первая игровая версия уютного Roblox-обби без внешних моделей и платных ресурсов.
Карта создаётся серверным скриптом при запуске игры.

## Открыть и поиграть

1. Установите Roblox Studio на Windows или macOS.
2. Откройте `build/WinterVillage.rbxlx` через **File → Open from File**.
3. Нажмите **Play**: появится новогодняя деревня. До запуска видна опорная площадка.
4. Клавиша **E** рядом со столом выдаёт чай, рядом со снежковой площадкой — снежки.
5. Выберите снежки в инвентаре и щёлкните по цели. Урона нет.
6. Обби начинается справа от места появления. Этапы проходятся по порядку;
   падение возвращает на последний этап. Прогресс хранится только до выхода.
7. Для публикации используйте **File → Publish to Roblox** в своём аккаунте.

Готовый файл находится в игнорируемом каталоге `build`. После клонирования соберите его командой ниже.

## Разработка

Нужен Rojo 7.6.1. В подготовленной облачной среде:

```sh
cd /workspace/roblox
/workspace/tools/rojo/rojo build default.project.json -o build/WinterVillage.rbxlx
```

Для синхронизации с локальной Studio установите официальный плагин Rojo и запустите
`rojo serve default.project.json` на своём компьютере из копии репозитория.
Подключите плагин к серверу Rojo. Не открывайте облачный сервер Rojo в Интернет.

- `src/server/init.server.luau`: карта, этапы, чай, Санта и серверная проверка снежков.
- `src/client/init.client.luau`: интерфейс, снег и прицеливание.
- `default.project.json`: структура проекта Studio.

## Проверки и ограничения

Проверены сборка Rojo, структура файла и компиляция двух Luau-скриптов.
Roblox Studio в Linux-среде недоступна: игровой запуск здесь не проверен.
Перед публикацией проверьте в Studio: все 15 прыжков, возврат после падения и смерти,
вход в оба дома, кресла, чай, Санту, снежки с двумя игроками и управление на телефоне.
Сейчас бросок рассчитан на мышь; мобильное управление ещё требует доработки.
Домики пока простые, с плоскими снежными крышами; звуков и сохранения прогресса нет.
