# Зимний парк

Уютная деревня Roblox без обби: два тёплых дома, три горки с санками,
каток, сугробы, снежковая площадка с мишенями и Санта.
Карта 400×360 создаётся сервером при Play; до запуска видна опорная площадка.

## Скачать и открыть

Откройте `build/WinterVillage.rbxlx` на GitHub и нажмите **Download raw file**.
В Roblox Studio (Windows/macOS): **File → Open from File**, затем **Play**.
Для публикации: остановите тест и используйте **File → Publish to Roblox**.

## Что делать

- **E** или экранная кнопка взаимодействия возле столика: взять чай.
  Выберите чашку и нажмите кнопку использования: рука поднимется, чашка наклонится,
  проиграется короткий звуковой эффект. Чай — декоративная механика без лечения.
- У подножия каждой горки **E** переносит на вершину; можно также подняться по лестнице.
  У санок **E** запускает спуск. Всего три маршрута разной длины и высоты.
  Санки движутся по заданному маршруту; свободного рулевого управления нет.
  После спуска персонаж выходит, санки возвращаются на старт. Прыжок позволяет выйти раньше.
- У горы снежков **E** выдаёт инструмент. Выберите снежки и щёлкните по цели.
  На сенсорном устройстве бросок направлен в центр камеры.
  Есть замах рукой, видимый снежок, след и рассыпание при ударе.
  Три мишени на площадке кратко белеют при попадании. Урона игрокам нет.
- У заготовки снеговика **E** добавляет детали: тело, голову, шарф и шляпу.
  Снеговик общий для игроков; через 45 секунд можно собрать снова.
- Лёд катка имеет пониженное трение. Специальной системы коньков пока нет.
- В домах кресла, ковры, книги, венки, подарки, свечи и открытый камин.
  Снегопад отключается внутри домов. Используются встроенные звуковые файлы Roblox;
  это короткие эффекты, а не записанные звуки чаепития или озвучка.

## Сборка и проверки

В подготовленной облачной среде:

```sh
cd /workspace/roblox
mkdir -p build
/workspace/tools/rojo/rojo build default.project.json -o build/WinterVillage.rbxlx
node tests/check-startup.mjs /workspace/tools/luau-check/node_modules/luau-web/src/index.js
```

Rojo: 7.6.1. Тест использует luau-web 1.5.1, установленный вне проекта.
При необходимости: `npm --cache /tmp/npm-cache install --prefix /workspace/tools/luau-check luau-web@1.5.1`.
Тест выполняет серверное создание объектов с упрощёнными заглушками API Roblox:
проверяет три саночных маршрута, два поднятых пола, два очага, три мишени и отсутствие обби.
Он не моделирует физику, анимацию, загрузку звуков или сетевую репликацию.
Клиентский код компилируется отдельно. Roblox Studio в этой Linux-среде недоступна.

Перед публичной публикацией проверьте в Studio:

1. Оба дома: пол без мерцания, ступени, кресла, огонь, отсутствие снега внутри.
2. Чай на R6 и R15: подъём руки, звук, сброс позы при смене инструмента.
3. Каждый спуск: лестница, посадка, спуск, выход прыжком и повторный запуск.
4. Два игрока: занятые санки, броски, попадания в мишени, отсутствие урона.
5. Телефон: экранные подсказки, использование инструментов, направление броска.
6. Границы карты, каток, производительность и окно Output без ошибок.

Исходники: `src/server/init.server.luau`, `src/client/init.client.luau`.
Для локальной синхронизации установите официальный плагин Rojo и выполните
`rojo serve default.project.json` на своём компьютере. Облачный сервер в Интернет не открывайте.
